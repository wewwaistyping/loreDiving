# 📖 Know My Setting (a.k.a. Lore Diving) [unstable alpha test]

Расширение для **SillyTavern** — превращает твои лорбуки в **визуальную интерактивную энциклопедию** мира.

> Креатор оформляет — игрок читает. Один лорбук = один мир, или склеивай несколько лорбуков в один сеттинг. Картинки, карты, спойлеры, заметки игрока, многоязычность, экспорт-импорт пакетами, live-связка с чатом.

---

## Что умеет

### Для креатора

- **Импорт ST-лорбука** — расширение автоматически разложит записи по категориям (персонажи / места / события / группы / спойлеры / …)
- **Smart merge при повторном импорте** — твои правки (длинный текст, картинки, теги, infobox-поля) **не теряются**. Удалённые из лорбука записи помечаются как orphan, не удаляются.
- **Multi-source** — один мир может содержать несколько лорбуков (например, основной + NPC-пак от соавтора). Smart merge работает per-source.
- **Многоязычные статьи** — RU/EN табы в редакторе, переключатель в reader.
- **Кастомные категории** — собственные эмодзи, infobox-поля, кнопки-команды для чата.
- **Спойлеры** — отдельная категория-спойлер + блочные `||spoiler||` внутри текста + глобальный toggle.
- **Карта мира** — загружаешь картинку, расставляешь пины, привязываешь к статьям.
- **Картинки** — auto-resize до 1920px (JPEG 85%), drag&drop, галерея с lightbox.
- **Экспорт мира** — единый файл `.kms.json` со всем контентом + картинки в base64.

### Для игрока

- **Чтение** — энциклопедия с категориями, поиском, тегами, infobox-карточками.
- **Заметки** — собственные заметки на любую статью, не теряются при обновлении лорбука креатором.
- **Избранное** (⭐), прочитано / не прочитано, дневник игрока.
- **Автоглоссарий** — упоминания других статей в тексте автоматически становятся ссылками (с поддержкой падежей через regex-ключи лорбука).
- **Live-tracking чата** — расширение видит когда в чате упоминается персонаж/место и подсвечивает его в каталоге + опциональный toast.
- **Кнопки-команды в чат** — на статьях появляются заготовки типа «спросить про X», подставляются в поле ввода ST.
- **Случайная статья** 🎲, поиск с подсветкой.
- **Импорт пакета** — получил `.kms.json` от креатора, импортнул, всё работает.

### Интерфейс

- **Drawer слева** на десктопе, изменяемый по ширине, fullscreen toggle.
- **Полноценный мобильный UI** — bottom tabs (📚 каталог · 📖 статья · 🗺 карта · ⋯ ещё), bottom sheets, immersive map.
- **Floating button** + хоткей `Alt+K` для быстрого открытия.

## Установка

### Через установщик SillyTavern

1. Открой **SillyTavern** → **Extensions** → **Install Extension**
2. Вставь URL:
   ```
   https://github.com/wewwaistyping/loreDiving
   ```
3. Жми **Install** → перезагрузи ST → включи расширение в панели Extensions.

### Вручную

1. Скачай или склонируй этот репозиторий.
2. Скопируй папку в:
   ```
   SillyTavern/data/default-user/extensions/knowMySETTING
   ```
   или (для старых версий ST):
   ```
   SillyTavern/public/scripts/extensions/third-party/knowMySETTING
   ```
3. Перезагрузи ST.

## Быстрый старт

1. Жми **📖** (floating button справа внизу) или `Alt+K` или меню расширений → **Know My Setting**.
2. **Импорт лорбука** — выбираешь свой `.json`, расширение разложит его по категориям.
3. Жми **✏️** в шапке (режим креатора) → у каждой статьи появится кнопка **«✏️ Редактировать»**.
4. Заполняй: длинный текст, картинки, теги, infobox-поля. Всё автосохраняется.
5. Хочешь поделиться? **📦 Экспорт** → получаешь `.kms.json` → отдаёшь другу. Он импортирует через **📂 Импорт пакета** и видит готовую энциклопедию.

## Технологии

- Чистый JS, без зависимостей (никакого React/jQuery).
- IndexedDB для хранения статей, медиа, миров, источников, категорий, карт.
- ST extension API (`SillyTavern.getContext()`) для интеграции и сохранения настроек.
- Все данные локальны — никаких внешних серверов, ничего не уходит наружу.
